# QVIDIA: Quantum Voltage Instrumentation and Distribution Intelligence Architecture

QVIDIA bridges the gap between quantum optimization and grid modernization. This system finds the optimal placement of phasor measurement units (PMUs) on the power grid. The algorithm completes the goal in the following steps:
1. A quantum approximate optimization algorithm (QAOA) is applied to find the set of possible best solutions.
2. A classical computing algorithm finds the best PMU configurations so that all buses are visible to the system, and redundancy is centered around critical points (in this case, the buses with the largest load).
3. Configurations of different quantities of PMUs are constructed, allowing for a cost-benefit analysis to show the benefit of adding extra PMUs for more redundancy and reliability.
4. The data is then visually plotted on an interactive graphical user interface to allow for the analysis of QVIDIA's results.

In order to try QVIDIA for yourself, you must interact with the QVIDIA.ipynb jupyter notebook, which starts from classical implementations of the algorithm to the full hybrid quantum-classical solution, finally displaying the quantum-classical soltuions on the graphical interface. 

A hybrid algorithm was developed to counteract the noise generated by quantum optimization algorithms. The quantum algorithm acts as a filter to reduce the size of the problem, ruling out the vast majority of possibilities. Then, our classical post-processing algorithm tests the remaining solutions and does heavier calculations to find the best solution for each quantity of PMUs.
