# QVIDIA

QVIDIA uses a hybrid quantum-classical approach to find the best sensor placements on a sample power grid. A quantum QAOA first finds the possible sensor placement configurations, then a classical algorithm filters the solutions to only the best and most redundant around important buses. 

To run the file and see our results:
1. Download this repository
2. Open a new qBaid instance
3. Import the whole repository (several dependencies are included here and are required for functionality)
